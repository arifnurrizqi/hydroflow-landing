Visibilitas operasional

Berhenti menebak kondisi air.

Pantau tanpa datang ke lokasi

Data perangkat dikirim ke server dan tersedia melalui dashboard berbasis web selama terhubung ke jaringan.

Punya catatan, bukan perkiraan

Setiap pembacaan tersimpan sebagai histori untuk penelusuran kejadian, evaluasi konsumsi, dan pelaporan.

Kemampuan sistem

Satu sumber data untuk operasional air.

Dirancang untuk menjawab kebutuhan monitoring harian, investigasi data, dan pengelolaan lebih dari satu perangkat.

01

Monitoring realtime

Lihat pH, turbidity, level tandon, sample flow, tegangan perangkat, sinyal, dan status koneksi dari browser.

02

Penggunaan air terukur

Pulse flow meter dikonversi menggunakan nilai kalibrasi untuk menampilkan konsumsi harian, bulanan, dan historis dalam liter.

03

Alarm berbasis ambang

Parameter yang melewati batas operasional ditandai agar tim dapat memeriksa kondisi lebih cepat dan melihat status penyelesaiannya.

04

Datalogger & export

Telusuri data mentah maupun agregat per jam, hari, bulan, dan tahun. Export CSV untuk pengolahan lebih lanjut di Excel.

05

Manajemen multi-device

Kelola banyak titik monitoring dari satu dashboard, lengkap dengan identitas, lokasi, konfigurasi, dan akses pengguna.

06

Kontrol perangkat terintegrasi

Kirim perintah drain valve melalui MQTT dan pantau acknowledgement perangkat pada instalasi yang mendukung fitur kontrol.

Cara kerja

Dari sensor di lapangan menjadi informasi yang jelas.

1

Perangkat membaca kondisi air

Sensor dan flow meter mengukur parameter yang dibutuhkan sesuai konfigurasi instalasi.

2

Telemetry dikirim ke server

Data masuk melalui API, divalidasi, dikonversi, dan disimpan sebagai histori yang dapat ditelusuri.

3

Tim memantau dan mengambil tindakan

Dashboard menampilkan kondisi terbaru, tren pemakaian, status kualitas, dan alarm pada perangkat terkait.

Data bergerak dari lapangan ke dashboard secara terukur

Penerapan

Fleksibel untuk berbagai titik air.

Konfigurasi perangkat, parameter, dan jaringan dapat disesuaikan dengan kebutuhan lokasi.

01

Tandon gedung

Monitor level, kualitas air, dan konsumsi pada jalur distribusi menuju gedung.

02

Fasilitas multi-lokasi

Satukan status beberapa titik atau cabang agar tim tidak memeriksa sistem satu per satu.

03

Utilitas proses

Sediakan histori parameter dan penggunaan untuk membantu evaluasi operasional.

04

Sistem khusus

Integrasikan sensor, interval pengiriman, dan batas alarm sesuai karakter instalasi.
